# 安全验证处理

自动验证功能已移除：不再提供自动处理开关，不取图、不导出网页像素、不隐藏拼图片段、不识别缺口、不模拟拖动，也不调用视觉模型。

保留轻量验证接口监听，独立于抓包和业务 RPC 版本。收到验证挑战或业务验证错误时暂停任务；用户在支付宝手动完成验证后，只有匹配当前账号、暂停令牌和挑战会话的真实 `data.result=pass` 才恢复调度。旧请求、旧挑战、重复回执不能解除新暂停，原有网络阻断继续保留。

不显示恢复弹窗，不发送验证通知，也不提供通知恢复按钮。没有收到匹配通过回执时保持暂停并记录日志。接口 Hook 安装失败会定期重试。

暂停只保存在当前进程内：重载配置仍保持暂停，真正结束并重启支付宝进程后重新检测，不读取历史持久化暂停。

本地回归不能代替真机验证；当前无已连接手机。不自动操作验证码。
