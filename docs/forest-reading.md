# 森林无纸阅读

在蚂蚁森林配置中开启“无纸阅读”（`readForest`，默认关闭），于森林常规任务结束后执行。

实现参考本地 Sesame-M 的 `ReadForestTask.java` 与 `ReadForestRpcCall.java`，不替换新村的阅读答题。使用小程序 `2021003114652763` 的授权码，在 `https://m.zhangwenwh.com/api/authorization` 换取阅读令牌；后续访问书城、章节、阅读时长、最近阅读与绿色能量进度接口。无需开启抓包。

- 仅选择 `price=0.00` 的免费书；读完自动换书，重复章节会停止。
- 每轮最多两分钟、120 章；未满额时保存下一章，下轮接续。
- token、书城日缓存、完成日期、书目与章节游标按支付宝账号分别保存于应用私有缓存。过期 token 重新授权；临时网络失败结束本轮，不写完成标记。
- 每章上报后查询服务端进度，满额立即结束；连续六章无收益停止。进度缺失或数值非法不能判定完成。
- 账号切换、日期变化、离线、安全验证暂停及任务取消后停止后续操作；在途 HTTP 请求随协程取消。授权调用使用一个独立、无队列的线程等待：底层服务忽略中断时，阅读任务仍可退出，新的授权等待旧调用结束，不再增加线程。
- 沿用参考项目的时长协议：单章上报 333～1000 秒，章节间实际等待 400～1200 毫秒，上报值不是实际等待时长。没有移植参考项目的章节预取与并发上报线程池。

日志标签为 `ReadForest`，输出服务端进度、结束原因和本轮已确认的能量差值，不输出授权码、令牌或响应正文。登录及实际能量结算仍需真机核验，单元测试及 APK 构建不能证明服务端接受。
