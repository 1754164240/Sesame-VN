## Change Log

## 0.10.0（2026-11-16）

- 自动 Release 显示名按 APK 版本号命名，构建标签附独立编号，避免覆盖历史版本与附件。
- 构建工作流统一使用 JDK 21，修复 Release Lint 在 JDK 17 下因缺失 List.removeLast 而崩溃的问题，保留检查与 Java 17 编译目标。
- 升级版本号，纳入金豆夺宝、神奇物种、芭芭农场、小鸡大厨、海洋 AI 摸鱼和森林寻宝六个范围的功能补齐。
- 纳入 Sesame-M 限流试用调整；新增业务开关默认关闭，具体变化见下方 2026-11-13 记录。

## 2026-11-13

- 新增金豆夺宝模块：双入口签到及任务、金猫矿工、乐园奖励、肥料／芝麻粒换豆、商城兑换及动态列表，新增业务默认关闭。
- 神奇物种补齐 V2 自动刮卡、抽卡道具使用时机、万能卡与赠卡精细筛选。
- 芭芭农场新增阿肥寻宝记、悬浮球游戏时长、施肥阶段丰收礼包和多阶段乐园限定任务。
- 庄园新增小鸡大厨／AI 厨房，独立完成食材任务、领奖和按库存自动制作美食，旧厨房保留。
- 海洋 AI 摸鱼新增默认鱼画鱼开通和点赞能量，分别配置、确认状态后推进。
- 森林寻宝新增独立任务／抽奖／助力控制、普通与活动强制助力、shareId 列表及任务黑名单。
- 对齐 Sesame-M 的限流配置供试用：默认 RPC 间隔 50ms，森林查询默认 500～1000ms，自己与好友主页分别限流，收能量接口间隔 0ms、排行榜 100ms；保留正确放行时间记录，已有查询间隔设置不自动覆盖。
- 蚂蚁森林新增默认关闭的“无纸阅读”，支持免费书阅读、自动换书、断点续读、账号隔离和满额停止，暂停或取消任务时停止请求。
- 安全验证监听独立于抓包；手动验证后根据当前账号和挑战会话的真实通过回执自动续跑。移除恢复弹窗、验证通知与手动恢复广播，保留其他网络阻断；重启进程不继承旧暂停。
- 修复验证事件排队导致有效请求被误判为过早、手动通过后不能续跑的问题。
- 移除自动解题、截图识别和模拟拖动实现。
- 修复森林蹲点恢复时重复查询、失败主页误判以及部分恢复覆盖剩余任务的问题，修正只收能量时段和离线、休眠判断。
- 修复 RPC 间隔时间记录，补充抽抽乐与青春特权的错误日志。
- 自动发布改用独立构建标签，保留历史版本及附件，合并重复发布步骤，PR 仅构建。
